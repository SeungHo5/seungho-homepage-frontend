브랜치 네이밍
```
main : 운영/배포 버전
develop : 다음 버전 개발 통합
feature : 기능 개발
```

예시
```
main
develop

feature/login
feature/blog
feature/user-profile

release/1.0.0

hotfix/login-error
hotfix/payment-error
```

커밋 컨벤션
```
feat: 새로운 기능
fix: 버그 수정
docs: 문서 수정
style: 코드 동작과 관계없는 스타일/포맷
refactor: 코드 구조 개선
chore: 설정, 패키지, 기타 작업
test: 테스트
```

예시
```
git commit -m "feat: 메인 페이지 추가"
git commit -m "fix: 네비게이션 모바일 오류 수정"
git commit -m "style: 코드 포맷 정리"
git commit -m "chore: Vite 개발환경 설정"
git commit -m "docs: README 프로젝트 설명 추가"
```

네이밍 컨벤션
```
변수 / 함수
→ camelCase
userName
getUserInfo()

React Component
→ PascalCase
BlogCard
UserProfile

Component 파일
→ PascalCase
BlogCard.tsx
UserProfile.tsx

폴더
→ lowercase / kebab-case
components/
blog-post/

Git Branch
→ prefix + kebab-case
feature/blog-page
fix/header-layout

상수
→ SCREAMING_SNAKE_CASE
MAX_RETRY_COUNT
API_BASE_URL
```
